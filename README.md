# Incentive-Mechanism-Design-for-Distributed-Ensemble-Learning
Incentive Mechanism Design for Distributed Ensemble Learning


#### To run experiments:

The code runs on Python 3. To run distributed ensemble learning (bagging) with 100 base learners on MNIST daataset, run
```
python simulation_bagging.py
```


To conduct incentive mechanism for bagging on MNIST dataset, run
```
python simulation_bagging_incentive_latency_mnist.py 
```
